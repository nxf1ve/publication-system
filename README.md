## Запуск прототипа лабораторной №6

Из корня проекта в PowerShell:

```powershell
npm.cmd --prefix client install
npm.cmd run dev
```

Откройте адрес, показанный Vite (обычно http://localhost:5173).
В PowerShell используйте `npm.cmd`, если выполнение `npm.ps1` запрещено политикой системы.
В терминале cmd можно использовать `npm run dev`.

На главной странице доступны добавление, редактирование, удаление с подтверждением,
валидация обязательных полей и фильтры по году, автору и типу.
Данные сохраняются в localStorage текущего браузера; сервер и PostgreSQL для прототипа не требуются.
Профиль и администрирование остаются заготовками полного приложения.

Проверка: `npm.cmd run build` и `npm.cmd test` из корня проекта.

Веб-приложение для учёта и управления публикациями сотрудников.

## Возможности

- просмотр и добавление публикаций;
- хранение данных о пользователях и публикациях;
- регистрация и авторизация пользователей с помощью JWT;
- разделы каталога, профиля и администрирования.

## Технологии

- **Frontend:** React, Vite, Axios;
- **Backend:** Java 17, Spring Boot, Spring Security, Spring Data JPA;
- **База данных:** PostgreSQL.

Проект разделён на две части: `client` содержит клиентское приложение, а `server` — REST API и серверную бизнес-логику. Инструкции по запуску находятся в README соответствующих каталогов.
