# Метрика №5: размер и длительность сборки

Client CI измеряет `npm run build`: время в секундах и суммарный размер
всех файлов `client/dist` в байтах и KiB (1024 байта), без сжатия.
Server CI измеряет полный `mvn --batch-mode verify` (включая тесты,
Checkstyle и упаковку) и суммарный размер `server/target/*.jar`.
Отдельные шаги установки зависимостей не входят в измерение.

Результаты публикуются в логах и Summary запуска GitHub Actions.
Артефакты `client-build-metrics` и `server-build-metrics` содержат JSON:
`duration_seconds`, `artifact_bytes`, `artifact_files`, `exit_code`.
При ошибке сборки размер и количество файлов равны `null`.
Отсутствие ожидаемых файлов после успешной команды также считается ошибкой.

Меньшее время означает более быструю сборку. Сравнивать запуски следует
с учётом окружения runner и кэша зависимостей. Это длительность команды,
а не скорость загрузки приложения или размер ZIP-артефакта GitHub.
